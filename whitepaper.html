01 Executive Summary

SLH Ecosystem is a Telegram-native digital investment house that combines traditional financial services with blockchain technology. Built in Israel by SPARK IND, the ecosystem consists of 20+ specialized Telegram bots, each serving as an independent micro-business within a unified economic framework.

The platform enables users to deposit cryptocurrency (primarily TON), earn yields through managed investment plans, trade tokens, manage inventory via SaaS tools, and participate in a gamified reward economy using internal tokens (SLH and ZVK).

02 Problem Statement

Traditional financial services remain inaccessible to millions of users, particularly in emerging markets. Existing crypto platforms suffer from complex UIs, high fees, and fragmented user experiences. Meanwhile, Telegram has become the de facto communication platform for crypto-native communities, with 950M+ monthly active users.

Key problems we address:

  • Fragmentation - Users need separate apps for trading, wallets, gaming, and community management
  • Complexity - DeFi protocols require technical expertise that excludes everyday users
  • Trust - Centralized exchanges face regulatory risks; pure DeFi lacks customer support
  • Accessibility - Many users in Israel and the Middle East lack access to global crypto platforms

03 Solution Architecture

SLH Ecosystem solves these problems by embedding financial services directly inside Telegram, where users already spend their time. Each bot serves a specific function but shares a common database, authentication, and token economy.

Architecture Principles

  • Telegram-Native - No separate app downloads; everything works inside Telegram
  • Modular Microservices - Each bot is an independent Docker container with its own codebase
  • Shared Economy - SLH and ZVK tokens flow between all bots
  • Double-Entry Ledger - Bank-grade accounting for all financial transactions
  • Multi-Language - Hebrew, English, Russian, Arabic, French support across all interfaces

Technical Stack

Python (aiogram 3) | PostgreSQL 15 | Redis 7 | Docker Compose | TON API | BSC/web3.py | CoinGecko | STON.fi DEX | Cloudflare | GitHub Pages

06 Technical Infrastructure

The entire ecosystem runs on Docker Compose with shared PostgreSQL and Redis instances:

  • 22 Docker containers orchestrated via single docker-compose.yml
  • PostgreSQL 15 with health checks, shared slh_main database
  • Redis 7 for caching, session state, and pub/sub messaging
  • Auto-restart on crash with exponential backoff
  • Double-entry ledger ensuring mathematical balance of all accounts
  • PBKDF2+XOR encryption for sensitive data (private keys, KYC)

Blockchain Integration

TON Network: Deposit verification, wallet management, payment processing via TonCenter API

BSC (BNB Chain): SLH ERC-20 token transfers, balance queries via web3.py

STON.fi: DEX swap quotes for TON pairs

CoinGecko: Live pricing for 12 cryptocurrencies, updated every 60 seconds
