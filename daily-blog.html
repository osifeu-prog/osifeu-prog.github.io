שלב מוסדי — מערכת ברמה רגולטורית + תיקון באג קריטי 2026-04-11 · ערב

נושא היום: בעקבות חשיפה של רישיונות בינלאומיים + 10 משקיעים של מיליון ומעלה, המערכת עוברת שדרוג לרמה מוסדית: יומן ביקורת בלתי-שביר, אינטגרציות CEX (Bybit + Binance) עם API Keys בקריאה בלבד, פורטל ניהולי ייעודי. במקביל, תוקן באג קריטי שגרם להיעלמות משתמשים.

שוחרר היום

  • 🏛 פאנל מוסדי ב-/admin.html: 4 דפים חדשים — Overview (סטטוס שרשרת + checklist תקינות), Audit Log (כפתור verify-chain + filtered entries), CEX Integrations (ניהול מפתחות Bybit/Binance), Portfolio (תצוגה מאוחדת), Compliance (checklist רגולטורית).
  • 🔒 Immutable Audit Log: טבלת institutional_audit עם SHA-256 hash chain, endpoint /api/audit/verify-chain שמאפשר לרגולטור לאמת שלא נערך שום שינוי היסטורי. כל פעולה (user.ensure, cex.key.link, cex.snapshot) כתובה כאן.
  • 🏦 CEX Integrations: /api/cex/add-key, /api/cex/keys/{user_id}, /api/cex/sync/{key_id}, /api/cex/portfolio/{user_id}. חתימות HMAC-SHA256 ל-Bybit V5 + Binance V3. מפתחות מוצפנים ב-DB (XOR+env key — שדרוג ל-AES-GCM בעבודה).
  • 💼 Wallet Page — תיק CEX מלא: סקציה חדשה שמציגה את כל המטבעות שלך מ-Bybit/Binance (לא רק TON) עם שווי USD + ILS, סנכרון ידני, והצגת breakdown מסודר לכל בורסה.
  • 🐛 CRITICAL FIX — "משתמשים נעלמים": כאשר משתמש התחבר עם Telegram ID ידני, המערכת שמרה ב-localStorage אבל לא שלחה ל-DB. כעת /api/user/ensure יוצר את המשתמש ב-web_users מיידית.
  • 🛡 Leaderboard: סינון test IDs (100001-299999, group chats) — מציג רק משתמשי Telegram אמיתיים (>= 1M).
  • 📊 Admin Dashboard counts: כולל רק real users בכל המטריקות (total_users, premium, staked, deposits, pending).
  • 🎨 Content: כותרת ראשית "SLH — האקוסיסטם של העולם החדש" (היה "בית ההשקעות הדיגיטלי"). nav: "להרוויח" (היה "הרוויח").
  • 🧹 Dashboard Portfolio: הוסר seed data (BTC/ETH/SOL/SLH mocks). התיק מתחיל ריק ומציג רק נכסים אמיתיים.

בעבודה עכשיו

  • Phase B — Strategy Engine: מנוע אסטרטגיות השקעה עם backtesting — יעד 65%+ תשואה שנתית דרך CEX optimization.
  • Phase C — Webhooks: מעבר מ-polling ל-webhooks לבוטים ב-Railway.
  • Phase D — Sumsub KYC: scaffolding מוכן, מחכה ל-API credentials.
  • Phase E — Fireblocks Custody: scaffolding מוכן, מחכה לחוזה.
  • AES-GCM Encryption Upgrade: החלפת ה-XOR הזמני ב-AES-GCM + KMS לפני production.

צפוי השבוע

  • השלמת כל בוטים "COMING" — 20+ בוטים מסומנים כ-active.
  • PancakeSwap Pool ל-SLH/BNB — ליסטינג DEX ראשון.
  • Network page: הרחבת אנימציית נוירונים + מחזיקי SLH מ-Binance.
  • Community: העלאת קבצים וקישורים.
  • מיזוג מדריכים לדף מרכזי אחד + תיקון theme switcher.

פעולה שנדרשת ממך

  • בדיקת הפאנל המוסדי: /admin.html → לחץ "Institutional" בצד ימין → verify-chain button.
  • חיבור API Keys: /wallet.html → "תיק CEX מלא" → "חבר API Key חדש" (Bybit או Binance, READ-ONLY!).
  • בדוק שמשתמשים לא נעלמים: התחבר עם ID ידני ממחשב אחר ← ודא שמופיע ב-/admin → Users.
  • ספק נתונים למיליונים: כדי להכניס 10 חשבונות גדולים למערכת — חבר את מפתחות ה-API שלהם דרך /wallet.html או ישירות דרך ה-admin panel.

Genesis 49 + רוטציית טוקנים + ZVK Pivot 2026-04-10

נושא היום: מסע השקה של 49 המשתמשים הראשונים (Genesis 49) — כל אחד מקבל NFT ייחודי + 10 ZVK כמתנה, דרך קוד GENESIS49 שמתמלא אוטומטית מה-URL. במקביל, רוטציה מלאה של 25 tokens של בוטים דרך BotFather, ומעבר מ-SLH כאסימון תגמולים (יקר, 444₪) ל-ZVK (זמין, ~4.4₪).

שוחרר היום

  • Genesis 49 Landing: עמוד onboarding.html עם 4 כרטיסי תגמולים, cookie banner (GDPR), 7-theme switcher, accessibility toolbar (WCAG 2.1).
  • getting-started.html: מדריך 7-שלבים (Genesis → Telegram → ID → Dashboard → Coupon → Display name → Wallet).
  • Token Rotation: החלפה מלאה של 25 Telegram bot tokens דרך BotFather (כולל Guardian שנכשל פעמיים ורוטר שוב).
  • ZVK Cashback Tiers: 100/50/150/500/1200/3000 ZVK לפי threshold של 1/5/10/25/50/100 distributions.
  • Dashboard Bug Fix: תיקון </script> inside template literal שהרס את הדף. manualLogin עם validation קפדני (7-10 ספרות).
  • Amount Correction: הורדת 3 אפסים מכל ה-ZVK amounts (10,000 → 10, 100,000 → 100) בהתאם ל-ZVK ≈ 4.4 ₪.
  • ZVK Strategic Pivot: החלפת SLH (444₪, יקר) ל-ZVK כאסימון תגמולים — שומר את SLH לאליטה ומאפשר distribution רחב.

פעולה שנדרשת ממך

חיווט Web3 הושלם — יתרות אמיתיות מהבלוקצ'יין 2026-04-09 · ערב

נושא היום: לקוחות רואים עכשיו יתרות אמיתיות על השרשרת בדשבורד ובדף הארנק. זו התשתית למסחר P2P: אם משתמשים לא יכולים לסמוך על המספרים — הם לא יסחרו.

שוחרר בפגישה הזו

  • Web3: מודול js/web3.js מבוסס ethers.js v6 — חיבור ל-MetaMask / Trust Wallet, קריאת יתרות מ-BSC (SLH, BNB, USDT) ו-Ethereum (ETH), חיבור אוטומטי חוזר, תגובה להחלפת חשבונות.
  • דשבורד: פאנל Web3 מלא בין כרטיסי ההפניות לפעילות אחרונה — כפתור חיבור כתום, שבב כתובת מקוצרת, רשת יתרות ל-4 טוקנים, גבולות בצבעי המטבעות.
  • דף ארנק: אותו פאנל Web3 ישר מתחת לכותרת, מחליף את ה-placeholder הריק הישן.
  • API: POST /api/user/link-wallet, GET /api/user/wallet/{id}, ו-POST /api/user/unlink-wallet — מאמת פורמט כתובת, מונע שיוך של אותו ארנק לשני חשבונות, שומר אותיות קטנות.
  • DB: מיגרציה אוטומטית מוסיפה עמודות eth_wallet, ton_wallet ואינדקסים חלקיים ל-web_users. גם נוצר SQL עצמאי ב-ops/migrations/20260409_web3_wallet.sql.
  • i18n: תרגומי פאנל Web3 בכל 5 השפות (HE/EN/RU/AR/FR).

עדיין בעבודה

  • חיבור ארנק TON דרך TonConnect (הפאנל כרגע מציג רק שרשראות EVM).
  • הוכחת בעלות על ארנק באמצעות חתימה (לרישום P2P).
  • רישום אוטומטי: /start בבוט מסנכרן משתמש ל-DB של האתר.
  • Course marketplace — קורסים דיגיטליים.

צפוי השבוע

  • ממשק P2P marketplace: רשום SLH במחיר שלך, חתום הצעה עם הארנק.
  • החלפה מלאה של 20 tokens של בוטים דרך @BotFather.
  • צ'אט בזמן אמת בקהילה (WebSocket).
  • קורס לדוגמה ראשון חינמי לבדיקת ה-marketplace.

פעולה שנדרשת ממך

  • החלף את כל ה-tokens של הבוטים דרך @BotFather (ראה SECURITY_TOKEN_ROTATION.md).
  • בדוק את הפאנל החדש: dashboard.html → "חבר ארנק" → ודא שיתרות BSC + ETH אמיתיות מופיעות.
  • צור Facebook App ב-developers.facebook.com לאינטגרציית פיד.
